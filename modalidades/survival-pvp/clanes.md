## <mark style="color:#9000df;">COMANDOS:</mark>

| Comando                        | Descripcion                                                       |
| ------------------------------ | ----------------------------------------------------------------- |
| /clan create \<nombre>         | Crea un clan                                                      |
| /clan invite \<jugador>        | Invita a un jugador al clan                                       |
| /clan accept \<clan>           | Acepta la petición para unirse al clan                            |
| /clan ally \<clan>             | Envía una petición de alianza                                     |
| /clan accept-ally \<clan>      | Acepta una petición de alianza                                    |
| /clan remove-ally \<clan>      | Elimina una alianza                                               |
| /clan chat \<mensaje>          | Envía un mensaje por el chat del clan o alterna el modo de chat   |
| /clan ally-chat \<mensaje>     | Envía un mensaje por el chat de alianza o alterna el modo de chat |
| /clan chest \<num>             | Abre un cofre del clan                                            |
| /clan disband                  | Elimina el clan                                                   |
| /clan promote \<jugador>       | Asciende a un jugador                                             |
| /clan demote \<jugador>        | Degrada a un jugador                                              |
| /clan kick \<jugador>          | Expulsa a un jugador                                              |
| /clan change-leader \<jugador> | Cambia el lider de un clan                                        |
| /clan home                     | Viaja al home del clan                                            |
| /clan sethome                  | Establece el home del clan                                        |
| /clan leave                    | Remueve al jugador del clan                                       |
| /clan info                     | Muestra la información del clan                                   |
| /clan members                  | Muestra los miembros del clan                                     |
| /clan allies                   | Muestra las alianzas del clan                                     |
| /clan level                    | Sube de nivel del clan                                            |
| /clan permission \<rango>      | Edita los permisos de un rango del clan                           |
| /clan rename \<nombre>         | Cambia el nombre del clan                                         |
| /clan settings                 | Edita los ajustes del clan                                        |
